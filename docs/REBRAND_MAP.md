# Rebrand Map: SDL Global Logistics → Advance Global Logistics

> **Context:** this platform is **already built and working**. This job rebrands it to **Advance Global Logistics** on
> its own domain. The design, colour palette, fonts, layout and every feature stay exactly as they are. Surgical
> replacements only, no rewrites. See `CLAUDE.md §0`.

This is the checklist for removing the previous brand. Tick each group as you finish it and note the commit.
The audit below was taken on 2026-10-03; re-run the greps in §5 because line numbers drift.

## 3. Scripted CSS prefix sweep (one commit, nothing else in it)

About 2,760 occurrences of `--sdl-*` and `sdl-*` across `src/**/*.css` and `*.tsx`. Do it with a short **Node** script
(Python isn't installed on the dev machine). Don't edit the occurrences one by one.

1. Scope: `src/**/*.{css,ts,tsx}` and `index.html` only.
2. Replace `--sdl-` → `--agl-`, then the class prefix `sdl-` → `agl-` **only when it is not preceded by a letter, digit or `_`**
   (word-boundary match), so file names, URLs and other words are left alone.
3. Before running: `grep -rnoE "[a-z0-9_]sdl-" src` must show nothing unexpected.
4. After: `npm run build` (zero TS errors) + a visual check of Home, Track Result and the admin dashboard at 375/1440.
   Styling must look **identical**; any unstyled element means a missed or broken name.
5. Commit: `rebrand: rename css prefix sdl- to agl-`.
